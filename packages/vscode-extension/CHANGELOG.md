# Changelog

## 1.0.0

- SNES and 65xx syntax highlighting, completion, diagnostics, navigation, and builds.
- Editable Git source projects, tracked research, immutable generations and previewed native merges.
- SQLite evidence storage, bounded analysis views and validated ROM/debug-map build receipts.
- Indexed PNG/palette editors and saved Aseprite/PNG export, review, application and recovery.
- Replay debugging and external emulator integration with explicit processor capabilities.
- Instruction and bus capture import, runtime evidence views, and storage maintenance.
- NES PPU bus/fetch/IRQ timelines, physical graphics reports and paused pattern/nametable/OAM inspection.
- NES mapper-qualified research and indirect targets, direction-sensitive hardware names, and portable graphics selection with physical CPU evidence joins.
- Famicom full machine contexts, controller input/screenshot companions and verified deterministic replay.
- Relocatable objects, libraries and linked builds with Asar/ca65 source adapters and opt-in linked source generation.

Requires VS Code 1.145.0 or newer. Bundled tools use the editor's runtime. Standalone npm tools
require Node.js 26 or newer. Live emulator support depends on a compatible external ares runtime.
See the
[guide](https://github.com/uttori/asm/blob/master/packages/vscode-extension/GUIDE.md) for setup and limitations.
